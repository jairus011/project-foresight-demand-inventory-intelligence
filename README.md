# Project FORESIGHT – Demand & Inventory Intelligence

## Overview

Project FORESIGHT is a collaborative data science project developed as part of the **Zidio Development Internship**. The objective is to build a demand forecasting and inventory intelligence system that helps businesses improve inventory planning, reduce stockouts, and optimize replenishment decisions using historical sales data and predictive analytics.

---

## Business Problem

Businesses often struggle to accurately predict product demand, resulting in:

- Stock shortages
- Overstocking
- Increased holding costs
- Lost sales opportunities

Project FORESIGHT addresses these challenges by combining data engineering, exploratory data analysis, forecasting models, and interactive dashboards to support data-driven inventory decisions.

---

## Objectives

- Build a robust data processing pipeline
- Perform exploratory data analysis (EDA)
- Engineer meaningful features
- Develop demand forecasting models
- Generate inventory risk scores
- Build an interactive Streamlit dashboard
- Deploy a scoring service/API
- Present insights and recommendations
